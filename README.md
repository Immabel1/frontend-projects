# Mini Web Apps

A collection of frontend web development projects built to practice HTML, CSS, and JavaScript fundamentals. This repository currently includes an Errand App and a Password Generator.

## Projects

### 1. Errand App

A simple task and errand management application that helps users organize and track errands.

#### Features

* Add new errands
* Mark errands as completed
* Remove errands from the list
* Simple and responsive user interface

#### Technologies Used

* HTML
* CSS
* JavaScript
* React

---

### 2. Password Generator

A web application that generates secure passwords based on user preferences.

#### Features

* Generate random passwords
* Adjustable password length
* Easy-to-use interface
* Instant password generation

#### Technologies Used

* HTML
* CSS
* JavaScript
* Typescript
